# English Learning Path · 英语学习路径

一个本地优先、内容由使用者掌控的开源英语学习中心，覆盖听力、阅读、写作与口语。程序**不附带商业题库、课程资料、受版权保护的录音或私人模板**；本地题包由使用者自行导入。

## 普通使用者：下载即用

> 当前工作区包含四科重开发预览，本次改动尚未创建 Release。正式版本请按 Releases 下载；预览版本可按下方开发说明构建。开发进度及验收记录见 [重开发记录](docs/REDEVELOPMENT.md)。

### Windows 10/11 x64

1. 打开右侧 **Releases**；
2. 下载最新的 `EnglishLearnPath-Windows-x64-Full-版本号.zip`；
3. 完整解压 ZIP；
4. 双击 `启动学习中心.exe`，程序会在默认浏览器中打开。

关闭浏览器标签页不等于结束本地服务。升级或删除旧版本前，请先在任意一个新版完整包中双击 `结束学习中心.exe`；它会结束所有仍在后台运行的 English Learning Path 启动器，但不会删除你选择的数据目录或学习记录。正常使用时也可以点击页面右上角“退出”。

Windows 完整包不需要安装 Node.js、Python 或数据库。源码 ZIP 不包含启动器和 Whisper 模型。

首次启动请选择长期保存学习数据的文件夹。程序旁的 `runtime-data/config.json` 只保存目录绑定，每个解压副本互相独立。换电脑时复制完整的数据文件夹，再重新绑定。

## 功能

- **写作**：自定义题目、计时、字数统计、本地历史与可选 AI 反馈；题目区支持选择图片或 Ctrl+V 粘贴图表、地图、流程图和截图，并随作文永久保存在本地。使用 DeepSeek 时，带题图的批改会自动调用官方 `deepseek-v4-flash-vision-exp`，将图片与正文放进同一次多模态请求；纯文字题仍使用已配置的文字模型。答题区支持专注模式，题目、计时和正文并排可见。不内置私人模板或课程讲义。
- **口语**：完整包内置 whisper.cpp 和 Whisper small.en。一次录音结束后自动在本机离线转写，音频不上传、无需 API Key；可回听、校对并一起保存录音和文字稿，再按需调用文字 AI 批改。Part 1、2、3 会把完整题目和明确的 Part 规则传给 AI；Part 2 先进行 1 分钟不录音准备，再自动进入最多 2 分钟回答。
- **阅读**：本地选题、原文与题目并排、计时与暂停、划线和笔记、自动保存、确定性判分、原文依据定位，以及全篇或仅错题重练。支持判断/选择、匹配、填空、多选、表格与题图。原文依据缺失时明确显示，不由 AI 编造。
- **听力**：按 Section 选题，离线播放、调速和回退，答案与播放位置一起保存。提交后显示原文，可回听和重练。音频故障会保留答案并提供重试。
- **整套模拟**：完整题包可声明三篇阅读或四段听力，题号必须连续覆盖 1–40。模拟计时不会因离开或重启页面而重置；听力按顺序原速播放一次。复盘恢复回放功能。生成材料明确标记，结果只显示答对题数，不充当官方估分。
- **题库与永久数据**：旧写说档案、计划与语料继续保存在 `EnglishLearnPath-data.json`；题库版本、媒体和听读记录分别保存在同目录的 `library/` 下。新题包不覆盖旧练习引用的题目版本，不使用浏览器缓存作为数据源。
- **完整备份**：导出包含学习档案、题库、媒体和练习历史的 ZIP；恢复前校验文件与引用关系，通过后绑定一个新档案目录，保留原档案。API 凭据不进入备份。旧版 JSON 导入/导出仍在兼容入口保留。
- **AI**：计时、编辑与本地保存离线可用；高级反馈支持使用者自己的 OpenAI 兼容 API 或本地模型。DeepSeek 当前公开的多模态 API 支持图片而不支持音频输入；口语音频始终由本机 Whisper 转成文字后再交给文字模型反馈。
- **本题复盘**：写作、口语均有独立批改页面，集中查看题目、原稿、题图 / 已保存录音及 AI 修改。报告把总分和小分放在最上方，依次展示总体评价、标注原文、确定错误、可选优化、目标范文和最终语料。口语会给出基于文字稿的暂定总分与 FC、LR、GRA 小分；发音因原始音频不发送给文字 AI，会明确标为无法仅凭转写判断。反馈支持 Markdown 标题、加粗、列表与表格；已保存的旧反馈也会自动排版。新批改保存提交时的原稿快照，不会被后续编辑覆盖。
- **原文标注与报告**：点击已批改记录进入报告页。写作只在原文中标红客观明确的语法、拼写或机械错误；措辞、自然度、简洁度、衔接和论证提升单独列为可选优化，不会把正确句子标错。点击标注可定位对应最小修改与原因；无法精确定位的建议保留在列表中。完整报告按标题分区并提供章节定位，标题不遮挡正文。可返回练习或编辑本题。记录以具体主题命名，题型作为辅助信息；查看旧报告不必再次请求 AI。
- **口语双稿**：原始转写原样展示；标点与大小写整理稿单独保存，修改标注显示在整理稿上。新口语批改一并生成，旧报告可点击 AI 整理按钮生成（会调用接口）。程序校验原词句没有被替换，整理失败不覆盖原稿。标注与修改卡片支持双向跳转；编辑答案时不重复显示旧报告正文。
- **四科计划**：填写考试日期、水平、重点和每日时间。新写作、阅读、听力每天各最多 1 项，新口语最多 2 次；复盘、重写、回听和语料记忆单列为任务。时间不足时推迟整项练习并显示原因，各科概览可勾选进度，首页汇总四科完成情况。旧计划没有设置听读时不会自行增加这些任务。
- **个人语料库**：由使用者按需点击“更新个人语料库”，阶段性汇总本机已经保存的旧记录和新增记录；不会每次答题都调用 AI。口语按真实个人经历和观点整理可迁移话题、自然表达与答题骨架，写作按领域整理词组、搭配和常用句式。只发送题目、答题文字和已有反馈，不发送录音或题目图片；结构化结果校验后保存在本地数据文件中。
- **错题本**：在写作或口语批改页逐条选择错句加入，保留参考修改、原因及原批改链接，不再整篇导入。复习时先自行纠错，再揭晓参考答案，按自评表现安排下一次复习；也可随时单独练习。旧笔记保留，仍支持手动记录、粘贴截图、图片放大和删除；表单完整显示，列表独立滚动。
- **单词本**：积累单词、短语、释义、搭配和例句；练习时先回忆再揭晓，选择“再练一次”或“记住了”，按表现安排复习并将进度保存在本地数据文件中。

## AI 配置

写作与口语批改会一并使用“学习计划”中已保存的现有水平、目标水平及重点，让修改建议贴合当前能力、示范答案对齐目标。未填写时会注明未提供，不会擅自设定目标分数。

进入“AI 与数据设置”，先选择 DeepSeek、OpenAI、本地模型或自定义服务预设，再填写 API Key。预设会自动填写接口地址和建议模型，连接测试成功后 AI 按钮才会启用。

所有服务商共用相同的 OpenAI 兼容请求和功能级输出契约。学习计划与个人语料库必须返回指定 JSON，写作与口语报告必须返回固定顺序的 Markdown 章节；本地代理会在内容进入网页前校验结构，拒绝不完整或错格式的返回，避免不同模型输出直接破坏页面。没有相应服务商 Key 时仍可通过自动化测试验证请求和解析流程，但不能代替该服务商真实账户的联网验收。

只有 DeepSeek API Key 时，选择 **DeepSeek** 即可：当前官方基础地址为 `https://api.deepseek.com`，页面建议使用 `deepseek-v4-flash`。模型名称可能变化，请以 DeepSeek 官方文档为准。

- 连接成功后，Windows 使用当前账户 DPAPI 加密并写入程序旁的 `runtime-data/ai-credentials.dpapi`。重启后会自动恢复，不需再次输入。
- Key 不写入浏览器缓存、学习数据 JSON、导出备份或发布包。“断开并删除已保存配置”会移除本机加密配置；更换电脑、系统账户或丢失对应密文/钥匙串条目后需重新输入。
- Windows 原地升级时保留自己的 `runtime-data` 目录。不要上传或分享这些配置。账户级加密不能防止已控制当前系统账户的恶意软件读取凭据。
- DeepSeek V4 的连接测试与正式批改默认使用非思考模式，避免思考预算耗尽而没有最终答案；正式反馈上限为 6000 token。
- 本地文字大模型需要使用者自行安装和启动；本地语音转写引擎和 small.en 模型已包含在 Full 完整包中，无需另外安装。
- 连接测试会发送一条极短请求，云端 API 可能收取极少量费用。

详见 [AI 配置说明](docs/AI_CONFIGURATION.md)。

## 练习内容

自行输入有权使用的写作题目和口语话题，或导入本地题包。内容授权说明见 [版权边界](docs/CONTENT_GUIDE.md)，题包与转换说明见 [本地题包格式](docs/QUESTION_BANK_FORMAT.md)。程序发行包不附带私人下载素材。

转换器只读取来源数据，不安装或运行来源项目。结构验证不等于答案正确性核验；来源不完整的图片、录音或题目会进入审查清单，不会靠猜测补齐。

旧版本的外部资源适配不再启用。旧数据文件中的未知字段和磁盘资源继续保留；新的听读模块使用独立记录，不把旧字段擅自解释为新格式。

## 隐私说明

学习记录永久写入你绑定的本地文件夹。程序在提交档案索引前保留滚动备份，并按天保留一份备份；旧档案兼容读取，首次增量保存后正文版本和媒体分别存盘；清除浏览器缓存或更换浏览器不会删除记录。换电脑时复制整个数据文件夹，再在新电脑上重新绑定即可。

请只分享官方 Release ZIP 或从干净源码构建的 ZIP，不要把自己已经运行过的整个程序目录重新压缩分享；Windows 已运行副本的 `runtime-data/config.json`都会包含你选择的数据目录路径。删除相应的小型配置只会重置文件夹绑定，不会删除绑定目录里的学习数据。

写作与口语都自动保存，不需要额外点击保存按钮：输入后会短暂防抖写盘；录音结束并完成 Whisper 转写后，音频与文字稿作为同一次保存写入本地档案，媒体独立存盘，后续校对也会继续自动保存。刷新或重新启动后可从历史记录恢复，录音也可另行下载。单条音频最大 16 MB；音频不会发送给配置的文字 AI 接口。本地转写可取消或重试，失败时录音仍会保留。

写作切换到 Task 1（Academic / General）时默认 20 分钟，Task 2 默认 40 分钟。仍可手动调整时间；载入历史作文会保留该记录保存的计时设置。

当你主动使用 AI 反馈时，作文或口语文字稿会发送给你配置的服务商；录音不会发送到配置的文字 AI 接口。请自行阅读相关服务商的隐私政策。

## 开发与构建

前端位于 `app/`，使用原生 HTML/CSS/JavaScript，无 npm 运行时依赖。`launcher/` 是仅使用 Go 标准库的本地启动器、本地文件存储和 AI 代理；完整包还会从 `launcher/cmd/stopper` 构建独立的后台服务结束工具。

开发者运行源码需要 Go 1.22+；构建完整包还需 CMake，以及对应系统的 C/C++ 工具链（GitHub Actions 已提供）：

```powershell
go -C launcher run .
```

构建 Windows 便携包：

```powershell
./build-portable.ps1 -Version dev
```

发布只构建 Windows 完整离线包，完整 Windows CI 成功后才能创建 Release。
