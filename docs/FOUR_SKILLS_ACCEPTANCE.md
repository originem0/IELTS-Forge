## 内容与发布边界

- 原始材料和本地转换题包没有放进程序 ZIP。可导入材料的入口说明位于本机 `question-banks/converted/START-HERE.md`。
- 阅读和口语来源未逐题人工确认；听力和两道写作题明确标为生成练习。软件流程通过不等于题目、答案或难度获得官方认可。
- 未转换的 109 篇阅读，以及缺图/缺音频或题号不一致的其他材料，均保留原件与核验记录。没有为了凑齐套题修改来源答案或伪造图片。
- 正式 Release 仍需现有 Windows 完整 CI 成功。当前只交付经过实际运行验证的 Windows 预览包。
- 旧写说档案中的内嵌录音和题图保留原格式，兼容加载与重启不丢失；此次没有把这些旧字段强制改为文件引用。新题库和听读媒体已单独存盘。
