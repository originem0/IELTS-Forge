# 学习材料与使用范围

公开源代码与程序发行包不附带商业题库、课程讲义、录音、范文库或私人学习资料。用户的本地素材整理与公开程序分发彼此独立。

应用内入门指南的示例和随程序提供的三题阅读、写作与口语热身为原创教学内容。它们用于熟悉题型与练习流程，不标为真题、不作正式难度或成绩依据。指南中的官方链接供查阅，外部试题不因此随程序分发。

可导入自行创作的材料、使用方式符合条款的官方公开示例、具有适当开放许可的内容，以及合法取得且仅作个人学习的材料。来源链接用于核对出处，不代表获得公开传播许可。

本地题库保留题干、配套图片、录音、答案和来源。真实考试、回忆题、生成题及未核验素材分别标注；出版年、题季年、考试年和收录年不能混用。官方样题不标成某年的真实考题，不能用下载时间证明题目新旧。

不要把无传播权的题包、完整学习备份、私人作文或口语录音随项目公开上传。程序 ZIP 与本地题库 ZIP 分开保存，API 凭据不进入两者。

格式与导入见 [题库说明](QUESTION_BANK_FORMAT.md)。项目为独立学习工具，与考试机构、出版社及题库平台没有官方隶属或背书关系。
