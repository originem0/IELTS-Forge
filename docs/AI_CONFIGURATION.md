# AI 配置说明

基础练习不依赖 AI。文字批改、学习计划和语料整理使用文字接口；带图题目可以使用同一个模型，也可以单独配置图片接口。

Task 1 General 书信使用对应的书信评分要求，纯文字题不需要图片接口。带图写作先把真实题图交给识图模型提取信息，页面展示可编辑的结果。用户对照原图核对并确认后，将确认后的信息与作文交给文字接口批改；文字批改不会收到图片，也不会声称看过原图。图表信息和本次确认快照随练习保存，更换题目或图片后必须重新提取。

## 两个接口，各自选择来源

文字接口和可选的独立图片接口都提供七种来源：中转站、OpenAI、Claude、GLM、Gemini、Grok、DeepSeek。选择官方来源会填写对应地址和协议；选择中转站后，填写站点提供的地址和协议。同一站点可以提供多个厂商的模型，模型名称不会改变接口协议。

填写 Key，点击“获取模型列表”，选中模型后保存并测试。服务商不提供模型列表时，可以展开“服务商不提供模型列表？”手动指定模型。程序不会猜测或自动替换模型名。两套配置分别获取模型、保存和删除，修改其中一套不会覆盖另一套。

支持 OpenAI 兼容 Chat Completions、Claude Messages 和 Gemini 原生协议。本地模型服务可通过“中转站 / 自定义地址”填写 OpenAI 兼容地址；本项目不会代替你启动文字模型服务。

## 独立图片接口可以不配置

不配置时，图表提取使用文字接口所选的地址、Key 和模型。该模型必须支持识图。设置页会显示当前实际使用的图片路由；尚未保存的表单改动不会影响它。

文字接口保存时只测试文字连接，因此纯文字模型也能正常使用。首次图表提取前，程序会发送一张随机色块测试图，要求模型正确读取颜色顺序，通过后才发送真实题图（不含作文）。验证结果随配置加密保存，重启后可复用；更换地址、协议、Key 或模型后需要重新验证。

配置独立图片接口时，保存前就会进行同样的识图测试。仅返回“CONNECTED”不算通过。测试不使用学习资料，但可能产生少量 API 费用。测试通过表示该配置能完成这次识图任务，不代表所有复杂图表都能准确识别。

带图请求始终携带真实图片。识图测试或图表提取失败时会保留原稿并报错，不会删除图片后继续请求，也不会擅自换模型或切回另一接口。识图失败不影响纯文字任务。删除独立图片配置后恢复使用文字接口，并在必要时验证该文字模型的识图能力。

## 本机保存与隐私

两套接口的来源、地址、协议、模型和各自的 Key 一起由 Windows 当前账户 DPAPI 加密，保存在程序旁的 `runtime-data/ai-credentials.dpapi`。重启自动恢复；旧版单接口配置也可恢复。留空的 Key 只会复用同一用途、同一地址及协议下保存的 Key，不会从另一个接口借用。

密钥不会返回浏览器，也不会进入学习备份或发布包。删除一套配置会保留另一套；两套都删除后移除加密文件。更换电脑或系统账户后需要重新输入 Key。

图表提取向识图服务发送题目和真实题图，不含作文；确认后，文字服务接收题目、核对后的图表信息与作文。口语录音由本机 Whisper 转写，转写后的文字可用于 AI 批改；录音不会发送给这里配置的 AI 接口。

## 听读错题讲解

完成作答后，可在逐题复盘中勾选 1–5 道错题，按需调用文字接口。发送所选题目、作答、标准答案与题库原文，生成中文讲解和逐字原文证据。程序校验证据确实存在，格式或证据不合格时自动重试一次；全部通过后才保存到本机。讲解不改答案、分数或练习完成状态。缺少原文时不生成，听力转写仍需对照音频核对。

引文校验只证明引用存在，不保证模型对它的解释正确。标准答案与原文有矛盾时应人工核对；讲解不推测用户是否漏听，也不生成未经核对的音频时间点。
