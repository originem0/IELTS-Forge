# 四科学习中心重开发

目标：保留现有写作、口语、离线转写、系统凭据和旧记录，接入本地题库、阅读、听力，并形成选题、作答、提交、复盘、再次练习的流程。程序和个人导入素材分离，不新增运行时依赖。

## 版本与验收

每版先实现，再审查数据安全、交互与错误路径，运行对应自动化测试；发现问题修复并复测。版本指开发里程碑，不自动发布 Release。发布仍须完整 Windows CI 成功。

- V1 题库和数据基础：固定题库格式、来源和验证状态、不可变内容版本、独立附件、独立练习记录；旧 JSON 不被导入覆盖。验证重复导入、非法数据、附件引用、目录隔离、重启恢复和冲突处理。
- V2 阅读与写说选题：转换本地来源，先核对 10–20 篇覆盖主要题型，再扩大导入；阅读并排作答、标记、计时、自动保存、确定性判分、证据复盘、错题重练；写作和口语从选题进入现有工作区，保留 Part/Task、题图和题目版本。浏览器测试验证整个流程及写说回归。
- V3 听力：核验音频、题目、答案和原文的配套关系；Section 练习、断点恢复、播放作答、判分、原文回听。缺少可靠时间戳不假造逐句定位。练习回放与模拟播放限制分开统计。
- V4 四科计划与模考：四科共用每日时间预算，保留复习优先和新题上限；首次作答和重练分开统计；完整且经过核验的试卷才进入整套模拟，不把随机单篇或生成题包装成官方估分。

## 数据约定

- `EnglishLearnPath-data.json` 暂时继续保存旧写说记录、计划和语料，不做破坏性全量迁移。
- `library/packs/<sha256>.json` 保存已验证结构的题包。编号由规范 JSON 内容生成；更新生成新版本，旧练习继续引用旧版本。
- `library/media/<sha256>.<ext>` 保存媒体；题包只存引用，不把音频塞进学习 JSON。
- `library/attempts/<id>.json` 保存听读练习，独立写入与备份；乐观版本检查防止旧页面覆盖新答案。
- 题库只接收固定结构的纯文本、选项、段落、图片和媒体引用，不执行来源 HTML/JavaScript。
- 来源中的作者示例不进入用户个人语料。来源状态区分未核验、核验过和生成素材；结构检查不等于答案正确性核验。
- 听读依照题目答案和规则判分，AI 不能改判；参考证据缺失如实展示。备份/恢复最终必须覆盖新目录，并兼容原有备份。
