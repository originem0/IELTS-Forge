# 更新说明 · 2026-10-02

本页记录当前开发分支的变化，发布版本以 [Releases](https://github.com/originem0/IELTS-Forge/releases) 为准。推送代码会触发 Windows 验证与打包，不自动创建公开 Release。

## 本次变更

- 学习计划改为一个主要练习加实际到期复习，按周轮换科目并参考真实耗时。修复每日 60、90 分钟时没有新题、120 分钟时没有新作文的问题；任务保留具体材料，计划调整与删除不清空学习历史。
- 语料自评接入间隔复习，写说首页与语料库共用清单。完成的旧答案先隐藏，未完成草稿继续恢复；单条表达可暂停，存档保留。提炼只使用有效的已完成作答，并区分图表、书信和论证表达；真实回答后可确认表达是否自然使用。
- 首页统一展示错句、词汇、语料、主动加入的笔记与听读错题。复习轮次受时间和尝试次数限制，错误至少间隔五分钟再练；单词支持识义与主动说写两种目的。任务完成自动关联实际作答和复习，手动确认继续用于回听等活动。
- 带图写作改为提取、人工核对、文字批改三个步骤。识图模型只接收题目和真实图片；用户可修改提取结果，明确确认后交给现有文字接口批改。核对内容自动保存，报告保留确认快照，题目或图片改变后需重新提取。
- 听读逐题复盘支持勾选 1–5 道错题生成中文讲解、易错点与原文引文，支持原文定位及返回。引用必须逐字存在于题库原文，格式或证据校验失败自动重试一次，全部通过后才保存；标准答案、判分和完成状态不变。
- 听读历史列表增加逐条确认删除，删除失败保留列表内容，成功后更新统计。后端核验数据目录和记录版本，防止旧页面误删新记录；删除首次作答不会破坏已有重练的继续保存。
- 首页雅思入门指南面向从未做过雅思题的学习者，补充 A/G 类、四科流程和时间、题型示例、评分与首次复盘路线。科目详情按需展开，保留阅读、写作与口语原创热身，附官方规则和样题链接。
- 导入器直接识别没有 ID3 标签的 MPEG Layer III 录音，ZIP 导入与媒体上传使用相同校验。音频保留原字节，不重新编码。
- 本地写作转换器先区分 General 书信与 Academic 图表题，不再因缺图跳过书信，也不会给书信错误配上旁边的图表。
- 完整题库可用一个 ZIP 导入。上传和解压内容上限调整为 1 GiB，单媒体仍限 128 MiB；媒体流式处理，较大的本地上传有独立期限。
- 来源与年份逐题区分，考试、出版、题季、编制和收录年份分别标注。旧来源的 verified 声明不会自动升级为真题认证；选题可检索年份与来源，收录年不充当出题年份参与优先排序。
- 同一来源按单元保留最新状态，隐藏新版本不会让旧题重新出现在选题中；同源不同题包的独有题目继续可用，旧版本保留供历史记录读取。
- 删除保护覆盖当前档案、听读记录、独立版本、滚动备份和每日备份。被引用题包不可删除，隐藏状态通过不可变新版本保存。
- 修复手填 Academic 题图保存时被浏览器内容安全策略拦截的问题，直接解码本地图片字节并保存到题库媒体。
- 构建在新暂存目录生成启动和结束程序，编译失败立即停止。最终题库测试直接接受交付 ZIP，替代依赖旧下载目录的临时验收脚本。
- 开发、审查、验收与维护文档合并为一份开发说明；移除过时的资料调查、阶段计划、私人交付记录和重复截图。

## 验证与升级

新增测试覆盖图表提取与文字批改分流、人工确认前不批改、核对内容刷新恢复和报告快照；听读讲解覆盖伪造引文拒绝与重试、删除冲突、真实磁盘保存、判分不变和窄屏定位。历史删除覆盖取消、请求失败、刷新恢复及原练习删除后的重练保存。AI 测试使用模拟模型响应，验证流程与数据边界，不代表真实模型的识图或讲解准确率。

新增回归覆盖原始 MP3 字节与 Range 播放、ZIP 大小边界、General 书信转换、来源验证、历史引用删除保护，以及可选本地题库归档的完整导入。浏览器检查覆盖写说报告、错题复习、三题阅读热身和四科练习；修正旧测试对隐藏历史列表、留白尺寸和每日轮换的过时假设。

Windows 目录恢复验收按实际文件身份比较，兼容 CI 临时目录的长路径和 8.3 短路径；测试断言失败时也会释放目录锁。

测试命令、可选题库验收与完整 Windows 包构建见 [开发与验收](DEVELOPMENT.md)。远程结果见 [GitHub Actions](https://github.com/originem0/IELTS-Forge/actions)。自动判分验证不代表题目已获官方认证，浏览器播放检查不能替代逐段人工听审。

升级时退出旧程序，完整解压新版到新目录，再绑定原学习目录。每个程序副本的 `runtime-data` 独立保存连接配置；不要删除原学习档案。分享程序时只分享干净的发行 ZIP，本地题库和个人数据不随程序发布。


## 可靠性修复（2026-10-04）

修复删除重练来源后无法备份、损坏记录阻断恢复、高版本档案错误回退、保存响应丢失导致持续冲突。补齐每日备份与健康记录抢救；不同记录的并发修改可以合并，真实冲突继续保护原数据。

停止录音先将音频落盘，再转写。写作累计时间与暂停状态、词汇和错句的未完成草稿可恢复。删除与 AI 结果在磁盘确认后才生效，失败恢复旧内容。学习日期按本地时区计算。

写说报告改为校验过的结构化结果；语料逐来源核验，格式自动重试总计最多一次。过长录音分段完整处理。远程 AI 地址要求 HTTPS，本机回环服务除外。

发布构建升级到受支持的 Go 工具链，并验收最终 ZIP 中的真实程序、保存重启、离线转写和退出。结束工具优先正常退出，备份压缩期间释放主存储锁。
